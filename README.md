# 🛒 Demo Web Shop – Manual & Automation Testing

---

## 📌 Project Overview

Demo Web Shop is a demo e-commerce web application tested using Manual Testing and Selenium Automation Testing.

The project focuses on validating core e-commerce functionalities including Registration, Login, Product Navigation, Shopping Cart, Checkout, and Logout.

---

## 👩‍💻 My Role

**Manual & Automation Tester**

- Prepared Test Plan, Test Scenarios, Test Cases, RTM, Bug Report, and Test Summary Report.
- Designed and executed manual test cases covering Registration, Login, Product Navigation, Shopping Cart, Checkout, and Logout.
- Performed Functional, Positive/Negative, UI, Boundary/Edge Case, and End-to-End Testing.
- Identified and documented defects during test execution.
- Automated key test scenarios using Selenium WebDriver, Java, and TestNG.
- Implemented Page Object Model (POM) for reusable and maintainable automation.

## 🤖 Automation Framework

The automation framework is developed using **Selenium WebDriver, Java, TestNG, Maven, and Page Object Model (POM)**.

The Page Object Model approach is used to separate page elements and actions from test cases, improving code reusability and maintainability.

### 🔄 End-to-End Workflow

**Registration → Login → Product Selection → Cart → Checkout → Order Confirmation → Logout**
